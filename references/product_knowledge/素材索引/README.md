## 使用规则

- 产品问答需要配图/视频时，先读 `多媒体素材库_检索入口.md`，再进入多媒体总索引。
- 项目制请求优先项目证据，不用基地课或泛课堂素材替代。
- 本地文件实际存在且授权允许时，可以直接返回或嵌入素材。
- 新素材的逐条信息只更新多媒体素材库；产品知识库仅在新增产品入口或检索规则变化时更新本页。
